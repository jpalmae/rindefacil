Guía de Uso Completa

Esta guía explica cómo usar {{ brand_app_name }} de punta a punta: crear gastos, subir boletas, entender validaciones antifraude, armar rendiciones y usar API Keys.

1. Flujo recomendado (resumen)

  1. Ingresa a Nuevo Gasto.
  2. Permite acceso a GPS y verifica que quede capturada tu ubicación.
  3. Sube foto/PDF de boleta para autocompletado con IA.
  4. Revisa monto, comercio, fecha y hora de boleta.
  5. Completa el motivo (mínimo 15 caracteres) y guarda.
  6. Agrupa tus gastos en una rendición y envíala a aprobación.

2. Crear un gasto correctamente

Ruta: Mis Gastos -> + Nuevo Gasto.

Campos obligatorios: monto, comercio, fecha, motivo y GPS activo.

Hora boleta: recomendable completarla siempre. Mejora la trazabilidad y la validación antifraude frente al momento real de rendición.

Boleta con IA: al cargar la imagen/PDF, el sistema intenta extraer monto, comercio, fecha y hora automáticamente.

3. Cómo funciona la validación antifraude

Cada gasto obtiene una validación Coherente, Parcial o Riesgo. Se calcula con:

  • Coincidencia entre comercio y dirección GPS capturada.
  • Coincidencia entre fecha de boleta y fecha de rendición.
  • Coincidencia entre hora de boleta y hora de rendición (margen de 20 minutos).
  • Rango horario habitual: lunes a viernes entre 09:00 y 19:00.

Regla especial: si el gasto cae en fin de semana o fuera de horario hábil, la validación no queda en “Coherente” (baja al menos a “Parcial”).

4. Crear y enviar una rendición

Ruta: Rendiciones -> Nueva Rendición.

Selecciona gastos en borrador, define título/descripcion y crea la rendición.

Cuando esté lista, envíala al flujo de aprobación para revisión de jefatura/administración.

5. Estados y alertas

  • Borrador: gasto creado, aún no enviado en rendición.
  • Enviado: está dentro de una rendición en proceso de aprobación.
  • Aprobado / Rechazado: resultado del flujo.
  • Advertencias: pueden aparecer por duplicados, políticas o score antifraude.

6. API Keys para agentes IA

Ruta: Mi Perfil -> API Keys para Agentes IA.

Cada usuario puede generar claves personales que heredan sus permisos para integrar Telegram, WhatsApp u otros agentes.

En API, para crear gastos también se debe enviar ubicación GPS (gps_latitude y gps_longitude).

Formato recomendado de fecha por API: DD/MM/YYYY.

7. Buenas prácticas para evitar rechazos

  • Rinde apenas ocurre el gasto (mejor score y mejor trazabilidad).
  • No edites manualmente comercio/fecha/hora si la boleta ya fue leída correctamente.
  • Sube imágenes nítidas, completas y sin cortes.
  • Describe claramente el motivo y su contexto de negocio.
